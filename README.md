# BaseLab — Next.js + Tailwind CSS

เว็บแอปเรียนรู้การแปลงเลขฐาน 2, 6, 8, 10 และ 16

## เทคโนโลยี

- Next.js App Router
- React + TypeScript
- Tailwind CSS
- Local Storage สำหรับเก็บคะแนนข้อสอบบนอุปกรณ์

## การใช้งาน

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000`
